## Reading order

1. Start with `../../PHASE_9_IMPLEMENTATION_SUMMARY.md`.
2. Read `PHASE9_FINAL_ACCEPTANCE.md` for the freeze decision and exact SHA/CI chain.
3. Use `final_system_browser/phase9_certification_manifest.json` for machine-readable runtime facts.
4. Use the numbered implementation reports for detailed design reasoning and step-level evidence.

Earlier Phase 1–8 evidence remains authoritative for the frozen functionality it certifies. Phase 9 evidence is additive and does not supersede the Phase 8 reproducibility, full-fresh 5M, Email export, or Direct Mail export proofs.
