## Reading order

1. Start with `../../PHASE_9_IMPLEMENTATION_SUMMARY.md`.
2. Read `../phase9_closure/PHASE9_CLOSURE_ACCEPTANCE.md` for current closure status and final-SHA readiness.
3. Read `PHASE9_FINAL_ACCEPTANCE.md` for the historical original freeze and exact SHA/CI chain.
4. Use `final_system_browser/phase9_certification_manifest.json` for machine-readable historical runtime facts.
5. Use the numbered implementation reports for detailed design reasoning and step-level evidence.

Earlier Phase 1–8 evidence remains authoritative for the frozen functionality it certifies. Phase 9 evidence is additive and does not supersede the Phase 8 reproducibility, full-fresh 5M, Email export, or Direct Mail export proofs.
