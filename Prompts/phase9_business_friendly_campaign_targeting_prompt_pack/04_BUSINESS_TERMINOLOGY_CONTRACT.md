# Phase 9 Business Terminology Contract

| Technical/Internal | Default Business UI |
|---|---|
| Historical Analysis | Learn from Past Campaigns / Past Campaign Insights |
| Positive population | Customers with the selected successful outcome |
| Unlabeled population | Hide from default UI |
| PU learning | Hide from default UI |
| Model | Targeting Intelligence |
| Model Training | Build / Refresh Targeting Intelligence |
| Prospect | Potential Customer |
| Prospect Scoring | Find Similar People / Evaluate Potential Customers |
| Propensity Score | Targeting Match Score |
| Scoring Run | Targeting Results |
| Audience Explorer | Find Target Customers / Target Group |
| Saved Audience | Saved Target Group |
| Rank Band | Match Strength |
| Percentile | Top Matching % |
| Algorithm | Advanced details only |
| Artifact SHA | Audit details only |
| Feature Contract | Audit details only |
| Current | Up to date |
| Stale | Needs refresh |

Required disclaimer:
“Targeting Match Score measures similarity/ranking against the validated targeting intelligence. It is not a guaranteed purchase probability.”

Do not use “customer” for the independent 5M demographic population in a way that implies historical identity linkage. Prefer “Potential Customer”.
